

# Password Strength Checker

## 1. Introduction

The Password Strength Checker is a beginner-friendly
Python project designed to check the strength of a
password entered by the user.

In today's digital world, passwords are important
for protecting personal information and online
accounts. A strong password helps improve account
security.

This program checks different conditions of a
password, such as its length, uppercase letters,
lowercase letters and numbers. Based on these
conditions, it displays whether the password is
Weak, Medium or Strong.

## 2. Objective

The main objective of this project is to develop
a simple password checking program using Python.

It helps beginners understand how strings,
conditional statements, loops and logical
operators work in a real-life application.

## 3. Features

- Accepts a password from the user.
- Checks the length of the password.
- Identifies uppercase letters.
- Identifies lowercase letters.
- Checks whether numbers are present.
- Displays password strength as Weak, Medium
  or Strong.
- Provides a simple and user-friendly output.

## 4. Technologies Used

- Programming Language: Python
- Software: VS Code / Python IDLE
- Operating System: Windows / Linux / macOS

## 5. Python Concepts Used

1. Variables – To store the password and checking
   results.
2. Strings – To handle the password entered by
   the user.
3. Input and Output – To accept the password and
   display the result.
4. For Loop – To check each character of the
   password.
5. If-Else Conditions – To identify password
   strength.
6. Logical Operators – To combine multiple
   conditions.
7. String Methods – To identify uppercase,
   lowercase and numeric characters.

## 6. Working of the Project

The program works in the following steps:

1. The user enters a password.
2. The program checks whether the password
   contains at least 8 characters.
3. It checks for uppercase letters.
4. It checks for lowercase letters.
5. It checks for numeric digits.
6. Based on the conditions, the program displays
   the password strength.

### Password Strength Categories

- Weak Password: Password contains fewer than
  8 characters.
- Medium Password: Password has at least
  8 characters but does not meet all the
  checking conditions.
- Strong Password: Password has at least
  8 characters and contains uppercase letters,
  lowercase letters and numbers.

## 7. How to Run the Project

1. Install Python on your computer.
2. Open VS Code or Python IDLE.
3. Create a new Python file.
4. Save the file as password_checker.py.
5. Copy the project code into the file.
6. Run the program.
7. Enter a password when asked.
8. Check the displayed password strength.
